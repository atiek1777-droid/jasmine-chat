# Nextra AI | نكسترا — دليل النشر (خطوة بخطوة)

مشروع دردشة ذكاء اصطناعي مجاني بالكامل، جاهز للنشر على Vercel. لا تحتاج أي خبرة برمجية — فقط اتبع الخطوات.

بما إن عندك تطبيق **Termux**، هذي أسرع طريقة تنشر فيها من جوالك مباشرة بدون متصفح ولا رفع ملفات يدوي. (لو تفضّل طريقة المتصفح التقليدية عبر GitHub، انزل لقسم "الطريقة البديلة" تحت.)

---

## 🚀 الطريقة الموصى بها: النشر من Termux مباشرة

### الخطوة 1: جهّز Termux

افتح Termux واكتب الأوامر هذي وحدة وحدة (اضغط Enter بعد كل سطر):

```bash
pkg update -y && pkg upgrade -y
pkg install git nodejs -y
```

هذا يثبّت Git و Node.js اللي نحتاجهم.

### الخطوة 2: اعطِ Termux صلاحية الوصول لملفات جوالك

```bash
termux-setup-storage
```

بيطلع لك إذن اضغط **Allow/سماح**. هذا يخليك توصل لملفات مجلد Downloads بجوالك.

### الخطوة 3: انقل ملف المشروع لـ Termux

نزّل ملف `jasmine-chat.zip` (اللي أرسلته لك بالمحادثة) لمجلد Downloads بجوالك، وبعدين بـ Termux:

```bash
cd ~
cp ~/storage/downloads/jasmine-chat.zip .
unzip jasmine-chat.zip
cd jasmine-chat
ls
```

المفروض تشوف الملفات: `index.html`, `package.json`, `README.md`, ومجلد `api`.

> إذا ظهرت رسالة "unzip: command not found" نفّذ أولاً: `pkg install unzip -y`

### الخطوة 4: احصل على مفتاح Groq المجاني

1. من متصفح جوالك روح لـ https://console.groq.com وسجّل دخول (بدون بطاقة)
2. من القائمة الجانبية **API Keys → Create API Key**
3. انسخ المفتاح (يبدأ بـ `gsk_...`) واحفظه مؤقتاً

### الخطوة 5: ثبّت أداة Vercel وانشر المشروع

```bash
npm install -g vercel
vercel login
```

بيطلب منك يفتح رابط بالمتصفح لتأكيد الدخول (بحساب Google أو GitHub أو بريدك) — افتحه ووافق، ورجع لـ Termux.

الآن أضف مفتاح Groq كمتغير بيئة سرّي:

```bash
vercel env add GROQ_API_KEY production
```

بيطلب منك تلصق القيمة — الصق مفتاح `gsk_...` واضغط Enter.

أخيراً انشر المشروع:

```bash
vercel --prod
```

بيسألك بضعة أسئلة بسيطة (اضغط Enter لقبول الإعدادات الافتراضية في أغلبها):
- `Set up and deploy?` → اكتب `y`
- `Which scope?` → اختر حسابك
- `Link to existing project?` → اكتب `n`
- `Project name?` → اكتب اسم مثل `jasmine-chat` أو اضغط Enter
- `Directory?` → اضغط Enter (المجلد الحالي)

بعد ثوانٍ بيعطيك رابط جاهز مثل:
`https://jasmine-chat-xxxx.vercel.app`

**هذا هو الرابط اللي تشاركه مع الناس ✅**

### كيف تحدّث الموقع لاحقاً؟

عدّل أي ملف (مثلاً بمحرر نصوص بـ Termux مثل `nano index.html`)، ثم من نفس المجلد:

```bash
vercel --prod
```

وينشر التحديث خلال ثوانٍ.

## 🖥️ الطريقة البديلة: عبر المتصفح و GitHub (بدون Termux)

### الخطوة 1: احصل على مفتاح Groq المجاني

1. روح إلى: https://console.groq.com
2. سجّل دخول بجوجل أو بريدك الإلكتروني (بدون بطاقة ائتمان إطلاقاً)
3. من القائمة الجانبية اختر **API Keys**
4. اضغط **Create API Key**، سمّه مثلاً `jasmine`، وانسخ المفتاح فوراً (يبدأ بـ `gsk_...`) — لن يظهر لك مرة ثانية
5. احتفظ فيه بمكان آمن مؤقتاً (Notes مثلاً)

---

## الخطوة 2: ارفع الملفات على GitHub (بدون سطر أوامر)

1. روح إلى https://github.com وسجّل دخول (أو أنشئ حساب مجاني)
2. اضغط **New repository** (زر أخضر)
3. سمّه مثلاً `jasmine-chat`، اختر **Public** أو **Private**، ثم **Create repository**
4. بصفحة المستودع الفارغة اضغط رابط **uploading an existing file**
5. اسحب كل الملفات والمجلدات من هذا المشروع (`index.html`, `package.json`, `README.md`, ومجلد `api` بكل محتواه) وأفلتها بالصفحة
6. اضغط **Commit changes**

---

## الخطوة 3: انشر على Vercel (دقيقتين)

1. روح إلى https://vercel.com وسجّل دخول **بحساب GitHub نفسه**
2. اضغط **Add New... → Project**
3. اختر مستودع `jasmine-chat` من القائمة واضغط **Import**
4. قبل الضغط على Deploy، افتح قسم **Environment Variables** وأضف:
   - **Name:** `GROQ_API_KEY`
   - **Value:** المفتاح اللي نسخته بالخطوة 1 (`gsk_...`)
5. اضغط **Deploy** وانتظر دقيقة تقريباً

بعد ما يخلص، بيعطيك رابط جاهز مثل:
`https://jasmine-chat-xxxx.vercel.app`

هذا هو الرابط اللي تشاركه مع الناس ✅

---

## الخطوة 4 (اختياري): اسم نطاق مخصص

من إعدادات المشروع بـ Vercel → **Domains** → أضف نطاقك الخاص إذا عندك واحد (مثل `jasmine-ai.com`)، واتبع تعليمات ربط DNS اللي تظهر لك.

## ميزة إنشاء الصور 🎨

المشروع الآن يقدر يسوي صور، بخدمة **Pollinations.ai** المجانية بالكامل (بدون أي مفتاح API إضافي، بدون حدود مزعجة):

- **تلقائياً داخل المحادثة:** لو المستخدم كتب "ارسم لي..." أو "صممي صورة..." أو "draw me a..." وهو بنص عادي، Nextra AI تكتشف الطلب تلقائياً وترسم الصورة مباشرة.
- **زر مخصص:** أيقونة 🖼️ جنب مربع الكتابة — لما تفعّلها، أي شي تكتبه يتحوّل مباشرة لطلب صورة (تُترجم وتُحسَّن الوصف تلقائياً عبر Groq قبل الإرسال لخدمة الرسم).

ما تحتاج تسوي أي شي إضافي — الميزة شغالة من نفس الإعداد الحالي (نفس مفتاح `GROQ_API_KEY`).

## ميزة الصوت 🎙️

الموقع الآن يدعم:

## حد الصور المجاني + قاعدة البيانات (Upstash Redis) 🖼️

الموقع الآن يدعم حد **3 صور بالساعة لكل جهاز** (بدل بلا حدود)، عشان يمهّد لتفعيل الاشتراك المدفوع لاحقاً. هذي الميزة **اختيارية** — لو ما ضبطت Upstash، الموقع يشتغل بلا حدود مثل قبل بالضبط.

**التفعيل:**
1. روح لـ 🔗 https://console.upstash.com وسجّل دخول بجوجل (بدون بطاقة ائتمان)
2. **Create Database** → اختر اسم ومنطقة قريبة
3. من صفحة القاعدة، انسخ من قسم **REST API**:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. بمشروعك على Vercel: **Settings → Environment Variables** → أضف المتغيرين بنفس الاسمين بالضبط، فعّلهم على Production
5. **Deployments → Redeploy**

## نظام الاحتياط التلقائي (Groq + NVIDIA NIM) 🛡️

الموقع الآن يدعم مزوّد احتياطي مجاني إضافي: **NVIDIA NIM**. الفكرة: كل الطلبات تروح لـ Groq أولاً (الأسرع)، ولو صار ازدحام (رسالة "الخدمة مزدحمة") أو تعطّل مؤقت، تتحول الطلبات **تلقائياً** لـ NVIDIA NIM بدون ما يحس المستخدم بأي فرق. هذا يضاعف طاقة موقعك الاستيعابية مجاناً.

**هذي الخطوة اختيارية** — الموقع يشتغل تمام بـ Groq لحاله بدونها. لو تبي تفعّلها:

1. روح لـ 🔗 https://build.nvidia.com وسجّل دخول (بريدك الإلكتروني، بدون بطاقة ائتمان)
2. من الإعدادات اختر **API Keys → Generate API Key**
3. انسخ المفتاح (يبدأ بـ `nvapi-...`) — **ملاحظة: هذا المفتاح صالح لمدة 6 أشهر بس، لازم تجدده بعدها**
4. بمشروعك على Vercel: **Settings → Environment Variables**
5. أضف متغير جديد:
   - **Name:** `NVIDIA_API_KEY`
   - **Value:** المفتاح اللي نسخته (`nvapi-...`)
6. اضغط **Save**، وبعدين من تبويب **Deployments** اضغط على آخر نشر → القائمة (⋯) → **Redeploy** عشان يتفعّل المتغير الجديد

## المحادثات المتعددة (زي ChatGPT) 💬

زر ☰ بالهيدر يفتح قائمة جانبية فيها كل محادثاتك السابقة، وزر + يبدأ محادثة جديدة مع الاحتفاظ بالقديمة. كل محادثة تُحفظ لحالها بمتصفح المستخدم (localStorage)، وأول رسالة بكل محادثة تصير عنوانها بالقائمة تلقائياً.

## أسئلة متوقعة

**كيف أحدّث الموقع لاحقاً؟**
عدّل الملفات مباشرة على GitHub (زر القلم ✏️ على أي ملف) واضغط Commit — Vercel ينشر النسخة الجديدة تلقائياً خلال ثوانٍ.

**سجل المحادثات — وين يُحفظ؟**
يُحفظ محلياً بمتصفح كل مستخدم فقط (localStorage). أنت كصاحب الموقع لا ترى محادثات أحد، ولا تُخزَّن على أي خادم. هذا خصوصية جيدة، لكن يعني لو المستخدم مسح بيانات المتصفح، تضيع محادثته.

**كم مستخدم يتحمّله المفتاح المجاني؟**
مفتاح Groq المجاني فيه حد مشترك تقريباً:
- 30 طلب في الدقيقة
- ~1000 طلب في اليوم

لعدد 100–1000 مستخدم بالشهر (استخدام متفرق خلال الشهر) هذا غالباً كافٍ جداً. لكن لو صار ضغط بنفس اللحظة (مثلاً كل الناس يجربون بنفس الساعة)، ممكن تظهر رسالة "الخدمة مزدحمة" مؤقتاً لين تتجدد الحصة (تتجدد باستمرار خلال الدقيقة/اليوم).

**لو كبر الاستخدام وصار يضيق؟** خيارات بالترتيب:
1. فعّل بطاقة على Groq (Developer tier) — يرفع الحد بحوالي 10 أضعاف، رسوم رمزية جداً حسب الاستخدام الفعلي فقط
2. أو خبرني وأضيف تبديل تلقائي بين أكثر من مزوّد مجاني (مثل Google AI Studio) عند الازدحام

**هل أقدر أغيّر الألوان أو الاسم أو الشعار؟**
كل شي بملف `index.html` — الألوان بأعلى الملف داخل `:root{...}`، والنصوص داخل كائن `STRINGS` بالأسفل. لو تبي تغييرات، اطلب مني وأسوّيها لك مباشرة.

## تسجيل الدخول (Firebase Authentication) 🔐

الموقع فيه الآن نافذة تسجيل دخول كاملة (Gmail + رقم الهاتف)، لكنها **معطّلة حالياً** لين تربطها بمشروع Firebase مجاني (5 دقائق):

1. روح لـ 🔗 https://console.firebase.google.com وسجّل دخول بجوجل
2. **Add project** → اختر اسم → أكمل الخطوات (عطّل Google Analytics، ما نحتاجه)
3. من الصفحة الرئيسية للمشروع، اضغط أيقونة **</> (Web)** لإضافة تطبيق ويب
4. سمّه أي اسم → **Register app** → بيطلع لك كائن `firebaseConfig` فيه قيم مثل apiKey, authDomain...
5. افتح `index.html` وابحث عن `const firebaseConfig = {` (بالجافاسكربت قرب النهاية)، واستبدل القيم الفارغة بالقيم اللي نسختها
6. من القائمة الجانبية بـ Firebase: **Authentication → Get started → Sign-in method**
7. فعّل **Google** (مجاني بالكامل، تفعيل بضغطة وحدة)
8. **رقم الهاتف اختياري:** فعّل **Phone** بس لاحظ إنه **يتطلب ترقية لخطة Blaze** (تحتاج بطاقة ائتمان/دفع مربوطة بـ Google Cloud) وتُحاسب على كل رسالة تحقق (~0.01$-0.46$ حسب الدولة). ما ننصح تفعّله إلا بعد ما يصير عندك دخل حقيقي من الاشتراكات يغطي التكلفة.

**بدون هالخطوة:** زر "تسجيل الدخول" يفتح نافذة توضح إنه "ما اتفعّل بعد" بدل ما يكسر الموقع — الشات نفسه يشتغل عادي بدون تسجيل دخول زي ما هو الحين.
